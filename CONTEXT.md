# Showhow

Showhow turns a recorded browser flow into a public, self-guided walkthrough.

## Language

**Walkthrough**:
An ordered set of steps that a reader can replay through a public link.
_Avoid_: Demo, tour, presentation

**Recording**:
An active capture session that adds steps to one walkthrough.
_Avoid_: Session, screen recording

**Step**:
One captured screen and its hotspot, title, and description within a walkthrough.
_Avoid_: Slide, frame

**Hotspot**:
The highlighted target a reader activates to advance from one step to the next.
_Avoid_: Marker, annotation

**Replay**:
A reader's progression through a walkthrough from its start overlay to its end overlay.
_Avoid_: Playback, viewing session
